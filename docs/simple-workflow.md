# 日常操作流程

## 自定义与标准叶型

1. 从自定义页调整进出口金属角、安装角、厚度和厚度位置；或从标准页选择 NACA65 / 双圆弧。
2. 成功预览后查看工程标签及 ID。更多形状参数、诊断图、头尾密切圆按需展开。
3. 选择目标数据库，保存叶型或导出 CSV / DAT；已保存列表可重新打开。
4. 自定义参数 JSON 和历史快照位于更多操作；同名备份增加修订，旧修订不覆盖。

预览失败会禁用相应保存/导出，不用迟到旧响应替换新结果。参数扫描不可行项逐条记录失败，不静默钳制。

## 数据库

- 点击样本激活预览，勾选最多四个样本并排比较；翻页保留勾选。
- 每个样本显示工程标签与完整 ID，导出对象在详情中明确显示。
- 垃圾桶按钮确认后逻辑删除当前数据库样本，同时清理选择、比较缓存和导出对象。
- 删除保留原始坐标文件与历史设计，重新扫描不复活；显式重新保存可恢复原生样本。
- 切换数据库会重置选择；异步操作固定在提交时的数据库，迟到响应不覆盖另一数据库状态。
- 扫描仅读取数据库第一层 DAT，保留原坐标与单位；链接、过大文件或不支持的点序逐项报错。

## 比较与三维导出

侧栏只保留自定义、标准、数据库三页。样本在数据库页并排比较，原生同系列样本可组合并导出 GeomTurbo。标准族的独立数学内核、CLI 拟合/基准/导出和既有数据保留，不再另设专项页面。

所有命令从项目根目录运行。浏览器脚本位于 `tests/browser/`，截图与隔离数据写入 `output/playwright/`，不写入源码或正式数据库。
