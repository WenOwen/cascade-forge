# 简化交互与设计保存流程（2026-09-12）

本轮围绕“知道去哪里、先调什么、保存后如何继续”完善界面。

## 使用入口

- 总览按目标提供四个入口：自己设计、生成标准叶型、筛选比较、组合三维叶片。
- 左侧分为日常设计与数据库维护。维护默认收起，进入维护页面时自动展开。
- 各业务页顶部用一句话说明用途，点击“怎么用”查看操作顺序和相关入口。
- 总览的“继续已保存设计”直接打开工作室中的“我的设计”。

## 叶型工作室

默认显示进口角、出口角、安装角、最大厚度和厚度位置五个常用参数。
头尾半径、局部形状及角度参考方向放入“更多形状参数与角度设置”。
厚度、曲率、角度图和头尾放大图集中在“形状检查”中，控制多边形按需显示。

数字框允许正常输入小数，越界时显示范围提示，不在输入中途改写数值。
只有当前参数成功预览后，保存和导出才会启用；失败时可恢复上次成功预览。
快速连续修改时，迟到的旧响应不会覆盖当前结果。

提供两种直接下载：

- 下载设计参数：Spec JSON，用于继续编辑。
- 下载叶面坐标 CSV：当前成功预览的局部归一化坐标，列为 side、point、x_over_c、y_over_c；不包含画布安装角旋转。

## 保存、重新打开与导入

1. 点击“保存设计”，填写名称与可选标签。同名保存生成新修订。
2. 点击“我的设计”，查看按最近保存顺序排列的列表；每页 12 条。
3. 选择“打开编辑”恢复参数、名称和标签；选择“下载备份”保存完整 JSON。
4. “导入设计”同时接受原始 Spec、含 spec 的几何 JSON，以及 Workspace 备份，成功后自动更新预览。

保存失败会保留弹窗与输入以便重试，提交期间阻止重复提交。
打开其他设计或离开页面时，确有未保存修改才提示；恢复已保存的成功预览会恢复对应的未保存状态。
打开失败的错误会显示在“我的设计”弹窗内，载入期间暂时禁止关闭，避免关闭后迟到的响应替换当前设计。
历史无时区保存时间按服务本地时间显示，不再重复增加八小时。
