# 数据库交互检查与完善（2026-09-12）

本轮覆盖 v2 数据库的检索、分页、选择、详情、导出和叶型比较流程。
保留工作区原有的 NACA 65、IGG 等未提交修改；只提交本轮改动。

## 已完成

| 原有问题或缺口 | 完成后的行为 |
| --- | --- |
| 筛选后仍返回全库总数 | 总数与状态、来源、ID 搜索条件一致，分页显示匹配总数和当前记录范围 |
| 无法定位指定 ID | 支持完整 ID 或片段搜索，忽略大小写和首尾空格；使用参数化查询，通配符按字面匹配 |
| 排序相同数值时分页顺序不稳定 | 增加 Geometry ID 次级排序；空库同样验证排序字段 |
| 只能升序、固定每页 50 条 | 新增升降序与 25/50/100 条选择 |
| 可无限翻到空页 | 禁用首页上一页、末页下一页，越界地址自动回到有效页 |
| 刷新丢失检索位置 | URL 保存已应用的条件和页偏移，刷新可恢复；提供重置筛选 |
| 加载状态和失败处理不清楚 | 表内显示加载/空结果/失败状态，错误持续可见并可重试 |
| 旧请求覆盖新筛选 | 请求序号隔离旧响应，仅最新查询可更新表格和按钮 |
| 跨页选中不可见、无法批量清空 | 显示跨页已选数量、本页全选及半选状态、清空选择 |
| 比较按钮没有遵守接口上限 | 仅选择 2–12 条时启用，页面明确说明限制 |
| 导出按钮没有说明格式及数量 | 明确单条导出，提供 CSV 坐标和 JSON 几何格式 |
| 详情页与后续检查脱节 | 详情内直接下载 CSV/JSON，并携带 ID 前往叶栅检查 |
| 比较输入重复或超限时反馈生硬 | 支持换行、空白、英文/中文逗号和分号，自动去重并提示有效数量 |
| 比较未显式提供基准差值 | 首项标记为基准，显示厚度、厚度位置和最大弯度差值 |
| 比较结果无法导出 | 新增 CSV 导出，保留完整数值精度、基准标记和差值 |
| 修改比较输入后旧结果容易被误用 | 清除旧图表/表格并禁用导出；请求中显示状态、阻止重复提交，忽略失效响应 |

选择在本页生命周期内跨筛选、跨分页保留；刷新恢复的是查询条件，不是选择集合。
差值是归一化几何量之差，不是百分比变化或气动性能指标。
